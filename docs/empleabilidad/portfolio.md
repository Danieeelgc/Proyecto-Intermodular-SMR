# 📂 Punto 5: Portfolio de Proyectos (Nexus Gaming Hub)

A continuación, presento el ecosistema de repositorios que conforman la infraestructura técnica de mi proyecto intermodular. Cada enlace dirige a la documentación específica, esquemas y configuraciones de cada área:

### 🎮 Infraestructura Principal
*   **[Redes Locales](https://github.com/Danieeelgc/Proyecto-Redes-Locales):** Diseño de la topología de red, segmentación de IPs y configuración de conectividad para el centro gaming.
*   **[Montaje y Hardware](https://github.com/Danieeelgc/Proyecto-Montaje):** Selección de componentes de última generación (plataforma AM5), análisis de rendimiento y presupuestos técnicos.

### 🗄️ Gestión y Sistemas
*   **[Bases de Datos](https://github.com/Danieeelgc/Proyecto-Bases-de-Datos):** Modelado Entidad-Relación y administración de datos mediante MySQL para el control de usuarios y hardware.
*   **[Sistemas y Ofimática](https://github.com/Danieeelgc/Proyecto-Ofimatica):** Documentación administrativa, gestión de inventarios y soporte del proyecto.
