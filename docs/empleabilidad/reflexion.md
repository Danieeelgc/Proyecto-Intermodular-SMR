# 🧠 Punto 6: Reflexión Personal sobre el Proyecto

Tras completar el desarrollo de **Nexus Gaming Hub**, he realizado un análisis sobre mi proceso de aprendizaje y la ejecución de este proyecto intermodular.

### 📝 Valoración del Proceso
Lo que más me ha aportado este proyecto es la **visión global**. Al principio, las asignaturas de Redes, Montaje o Bases de Datos parecen mundos distintos, pero al crear Nexus Hub he comprendido que son piezas de un mismo puzle. No puedes tener una buena experiencia gaming sin un hardware potente (AM5), pero tampoco sin una red optimizada y una base de datos que gestione a los usuarios.

### 🏆 Lo más positivo
*   **La Lógica Técnica:** Ver cómo una configuración de red o una base de datos que has diseñado "desde cero" funciona correctamente y permite que los datos fluyan sin errores.
*   **El Desafío del Montaje:** Seleccionar componentes y asegurar la compatibilidad total del sistema me ha dado mucha confianza para entornos reales.

### ⚠️ Retos y Dificultades
El mayor desafío ha sido la **organización lógica**. Estructurar correctamente las tablas de la base de datos y asegurar que el direccionamiento IP no generara conflictos fueron los puntos donde más tuve que investigar. Sin embargo, superar estos obstáculos es lo que realmente me ha ayudado a mejorar mi capacidad de resolución de problemas.

### 🏁 Conclusión Final
Este proyecto me ha servido para confirmar mi vocación. Me motiva ver resultados tangibles de mi trabajo y me siento preparado para seguir profundizando en la administración de sistemas y redes en el futuro.
