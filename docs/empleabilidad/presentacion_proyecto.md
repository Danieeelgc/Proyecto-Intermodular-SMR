# 🚀 Punto 4: Presentación de Nexus Gaming Hub

Esta es la memoria de presentación de mi proyecto integral para el centro de alto rendimiento gaming.

## 🎯 Objetivo del Proyecto
El propósito de **Nexus Gaming Hub** es proporcionar una infraestructura tecnológica de vanguardia para jugadores profesionales y entusiastas de los eSports. El proyecto garantiza máxima potencia de procesamiento y una latencia de red mínima.

## 🛠️ Soluciones Técnicas Implementadas

### 1. Infraestructura de Hardware (AM5)
*   **Decisión:** He optado por la plataforma **AM5** para asegurar la longevidad del centro.
*   **Beneficio:** Permite actualizaciones futuras de CPU sin cambiar la placa base, optimizando la inversión a largo plazo.

### 2. Diseño de Redes Locales
*   **Configuración:** Implementación de una topología de red con segmentación de IPs para jugadores y administración.
*   **Rendimiento:** Uso de switches gigabit para garantizar que el "ping" sea el más bajo posible en entornos competitivos.

### 3. Gestión de Datos (SQL)
*   **Sistema:** Creación de una base de datos relacional en MySQL para gestionar:
    *   Inventario de hardware.
    *   Registro de usuarios y sesiones de juego.
    *   Control de mantenimiento e incidencias.

---

## 📈 Valor Añadido (¿Por qué Nexus Gaming?)
Nexus Gaming Hub no es solo una sala de ordenadores; es un sistema integrado donde el hardware está optimizado para el software actual y la red está diseñada para soportar cargas críticas sin pérdida de paquetes.

## 🎓 Conclusiones del Aprendizaje
Durante el desarrollo de este proyecto, he aprendido que:
*   La planificación previa en **Packet Tracer** ahorra horas de errores físicos.
*   Una base de datos bien estructurada facilita la escalabilidad del negocio.
*   El montaje de hardware requiere una selección equilibrada para evitar cuellos de botella (bottleneck).
